# HR Analytics Dashboard

## Overview
This project is an interactive Human Resource dashboard built using Power BI.

The dashboard analyzes:
- Employee attrition
- Workforce demographics
- Salary distribution
- Overtime impact
- Department-level attrition trends

## Features
- KPI cards
- Interactive slicers
- Employee attrition analysis
- Workforce demographics
- Salary insights
- Department analysis

## Tools Used
- Power BI
- DAX
- Data Visualization
